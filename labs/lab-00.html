Assignment vs equality

In math, \(=\) often means “these are equal.” In code, a single = almost always means assignment: “compute the right-hand side and store it under this name.”

n = length(x)    % Octave: store the length of x in the name n
n = len(x)       # Python: same idea

After that line runs, n holds a number. Checking whether two things are equal uses a different symbol later (== in both languages); you do not need that today.

Functions look like \(f(x)\)

A function has a name. You call it by writing the name, then parentheses, then an input.

Math idea In words Role in code
\(f\) the function’s name often a language word such as length or len
\(x\) the input you give it often a name you chose such as x
\(f(x)\) “do \(f\) to this input” length(x)
\(y = f(x)\) “store the result as \(y\)” n=length(x)

So length(x) means: run the built-in named length on the object you named x. The result is a number (how many entries x has).

The data

Use this 6-vector of Arcata morning temperatures, in °F, for six successive hours: \[ x = (52, 51, 53, 55, 58, 60). \] Entry \(x_1\) is 7 a.m.; \(x_6\) is noon. Work C0.1–C0.6 in order.

C0.1 — Enter and index

Create a vector named x. Print n, the first entry, the last entry, and Boyd’s third entry \(x_3\).

Octave (demo — run this):

x = [52, 51, 53, 55, 58, 60];
n = length(x)
x(1)
x(n)
x(3)

Python (demo — run this):

import numpy as np
x = np.array([52, 51, 53, 55, 58, 60])
n = len(x)
print(n, x[0], x[-1], x[2])

Expected output (values): \(n=6\), first entry \(52\), last entry \(60\), third entry \(53\).

Check What quantity does \(x_3\) represent (include units)? Write the command that prints that entry.

C0.3 — Scale

Using your corrected x from C0.2, create a vector named doubled equal to 2*x. Print doubled.

Expected output: \((104, 102, 108, 110, 116, 122)\).

C0.4 — Add a vector

Create a vector named ones6 of six ones (every entry \(1\)). Then create warmer by adding five degrees to every hour: warmer=x+5*ones6. Print warmer.

Expected output: \((57, 56, 59, 60, 63, 66)\).

Hints for ones6: Octave ones(1,6) or [1,1,1,1,1,1]; Python np.ones(6) or np.array([1,1,1,1,1,1]).

Check: Record warmer. Why is x+5 (adding a scalar) not the same idea in the mathematics of this course, even if software accepts it?

C0.5 — Plot \(x\), \(2x\), and \(-x\)

Plot the corrected x, 2*x, and -x versus hour index \(i=1,\ldots,6\). Include a legend.

Octave:

i = 1:6;
plot(i, x, '-o', i, 2*x, '-o', i, -x, '-o');
legend('x','2x','-x');
xlabel('hour index i');
ylabel('value');

Python:

import matplotlib.pyplot as plt
i = np.arange(1, 7)
plt.plot(i, x, '-o', label='x')
plt.plot(i, 2*x, '-o', label='2x')
plt.plot(i, -x, '-o', label='-x')
plt.xlabel('hour index i')
plt.ylabel('value')
plt.legend()
plt.show()

Check: In one sentence, what did multiplying by \(-1\) do in the picture?

### Functions look like $f(x)$

A **function** has a name. You **call** it by writing the name, then parentheses, then an **input**.

| Math idea | In words | Role in code |
