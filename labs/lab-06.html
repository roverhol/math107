What we are doing

Solve an inconsistent overdetermined system in the least-squares sense: compute \(\hat{x}\), plot data vs fit, report residuals and RMS, check \(A^{\mathsf{T}}r\approx 0\), and decide whether the model is useful in context.

Learning objectives

  1. Compute a least-squares fit with Octave or Python.
  2. Plot observed and fitted values.
  3. Interpret residuals and an RMS error in context.
  4. Check orthogonality of the residual to the columns of \(A\).
  5. Judge whether a fitted model is useful, not just report coefficients.

Math connections

Inconsistent \(Ax=b\) and \(\min_x\|Ax-b\|\) (Lecture 38); normal equations, RMS, orthogonality, and \(A^{\mathsf{T}}A\) PSD/PD (Lecture 39).

Key syntax (this lab)

Task Octave Python
Tall \(A\), column \(b\) A = [1 0; 1 1; 1 2]; b = [1; 2; 2] A = np.array([[1.,0],[1,1],[1,2]]); b = np.array([1.,2,2])
Least-squares \(\hat{x}\) xhat = A \ b xhat = np.linalg.lstsq(A, b, rcond=None)[0]
Fitted / residual bhat = A*xhat; r = b - bhat bhat = A @ xhat; r = b - bhat
Norm / RMS norm(r); norm(r)/sqrt(rows(A)) np.linalg.norm(r); np.linalg.norm(r)/np.sqrt(A.shape[0])
Orthogonality A'*r A.T @ r
Scatter + fit line plot(t, b, 'o', t, bhat, '-') plt.plot(t, b, 'o', t, bhat, '-')

Indexing reminder: Boyd \(x_1\) is 1-based. Octave is 1-based; NumPy is 0-based.

Demo (optional — run once)

Monday’s tiny inconsistent system: \[ A=\begin{bmatrix}1&0\\1&1\\1&2\end{bmatrix},\qquad b=\begin{bmatrix}1\\2\\2\end{bmatrix}. \]

Octave:

A = [1 0; 1 1; 1 2];
b = [1; 2; 2];
xhat = A \ b
r = b - A*xhat
A'*r          % near zero

Python:

import numpy as np
A = np.array([[1., 0.], [1., 1.], [1., 2.]])
b = np.array([1., 2., 2.])
xhat = np.linalg.lstsq(A, b, rcond=None)[0]
r = b - A @ xhat
print(xhat, r, A.T @ r)

Expected: \(\hat{x}\approx(1.167,\,0.5)\); \(A^{\mathsf{T}}r\approx(0,0)\).

Exercises

Pick Octave or Python for the term. Use column vectors for \(b\) and \(\hat{x}\).

E1. Impossible by hand, possible by least squares. Let \[ A=\begin{bmatrix}1&0\\1&1\\1&2\end{bmatrix},\qquad b=\begin{bmatrix}1\\2\\2\end{bmatrix}. \]

  1. Argue briefly that \(Ax=b\) has no exact solution (two equations already force a third that fails).
  2. Compute \(\hat{x}\) with A\b / lstsq.
  3. Report \(\hat{b}=A\hat{x}\), \(r=b-\hat{b}\), and \(\|r\|\).

Expected (rounded): \(\hat{x}\approx(1.167,\,0.500)\); \(\|r\|\approx 0.408\).

E2. Real-ish line fit. Five evening study-hour totals \(t=1,\ldots,5\) (hours) and self-reported focus scores \(b\) (0–10): \[ b=(3.0,\,4.5,\,4.0,\,6.5,\,7.0). \] Use the model \(b\approx x_1 + x_2 t\) with \[ A=\begin{bmatrix} 1&1\\1&2\\1&3\\1&4\\1&5 \end{bmatrix}. \]

  1. Compute \(\hat{x}\).
  2. Compute \(\hat{b}\), \(r\), and \(\mathrm{RMS}=\|r\|/\sqrt{5}\).
  3. In one sentence: on a 0–10 focus scale, is this RMS small enough to call the line useful?

Expected: \(\hat{x}=(2,\,1)\) (exact from normal equations); RMS \(=\sqrt{3/10}\approx 0.548\).

E3. Plot. Using the E2 data, plot observed \(b\) vs \(t\) as markers and fitted \(\hat{b}\) as a line (same axes). Label axes. Does the line capture the overall trend despite the dip at \(t=3\)?

Expected answer: yes — upward trend; \(t=3\) sits below the line (visible residual).

E4. Orthogonality. For your E2 fit, compute \(A^{\mathsf{T}}r\). How close to \((0,0)\) is it? Why should it be near zero?

Expected: entries on the order of \(10^{-15}\) (roundoff); residual \(\perp C(A)\) at a least-squares solution.

E5. Usefulness, not just coefficients. A classmate reports only “\(\hat{x}=(2,\,1)\)” with no plot and no RMS.

  1. What two checks would you still demand?
  2. Suppose instead RMS \(=3.5\) on the same 0–10 scale. Useful linear model? Why or why not?

Expected: (a) plot / residual look + RMS (or \(\|r\|\)) in context; (b) not useful — typical error is huge relative to the score scale.

E6 (stretch). PSD check. Form \(P=A^{\mathsf{T}}A\) for the E2 matrix \(A\). Verify \(P^{\mathsf{T}}=P\) and, for \(x=(1,-1)\), that \(x^{\mathsf{T}}Px=\|Ax\|^2\ge 0\). Are the columns of \(A\) independent? Is \(P\) positive definite?

Expected: yes independent (Vandermonde-style line model); \(P\) PD, so \(\hat{x}\) unique.
