What we are doing

Treat a matrix as a geometric machine: predict where points go under scaling, reflection, shear, and rotation; apply \(A\) to many points at once; plot before/after.

Learning objectives

  1. Predict the effect of scaling, reflection, shear, and rotation matrices.
  2. Apply a matrix to many 2D points stored as columns (or rows) of a data matrix.
  3. Plot original and transformed shapes and compare.
  4. Adapt a short program that implements a transformation.
  5. Interpret a matrix as a coordinate or physical-space transformation.

Math connections

Matrix dimensions and structure (Lecture 18); \(Ax\) as a linear combination of columns (Lecture 19); geometric maps and “columns = images of \(e_j\)” (Lecture 20).

Key syntax (this lab)

Task Octave Python
Matrix A = [1 0; 0 -1] A = np.array([[1., 0.], [0., -1.]])
Matrix–vector A*x A @ x
Many points as columns Y = A*X Y = A @ X
2D scatter / line plot plot(X(1,:), X(2,:), 'o-') plt.plot(X[0], X[1], 'o-')

Indexing reminder: Boyd \(A_{ij}\) is 1-based. Octave matrices are 1-based; NumPy is 0-based.

Demo (optional — run once)

Triangle with vertices \((0,0)\), \((1,0)\), \((0,1)\) as columns of \(X\), then rotate \(90^\circ\) CCW by \(A=\begin{bmatrix}0&-1\\1&0\end{bmatrix}\).

Octave:

X = [0 1 0; 0 0 1];          % columns are points
A = [0 -1; 1 0];
Y = A*X
plot(X(1,:), X(2,:), 'bo-', Y(1,:), Y(2,:), 'rs-');
axis equal; legend('original','transformed');

Python:

import numpy as np
import matplotlib.pyplot as plt
X = np.array([[0., 1., 0.], [0., 0., 1.]])  # columns are points
A = np.array([[0., -1.], [1., 0.]])
Y = A @ X
plt.plot(X[0], X[1], 'bo-', Y[0], Y[1], 'rs-')
plt.axis('equal'); plt.legend(['original', 'transformed']); plt.show()

Expected: \(Y=\begin{bmatrix}0&0&-1\\0&1&0\end{bmatrix}\) (columns \((0,0)\), \((0,1)\), \((-1,0)\)).

Exercises

Pick Octave or Python for the term. Store points as columns of a \(2\times N\) matrix unless a prompt says otherwise.

E1. Predict, then compute. Let \(A=\operatorname{diag}(2,1/2)\) and \(x=(1,1)\).

  1. Predict \(Ax\) without software.
  2. Check with code.
  3. In one sentence: what did \(A\) do geometrically?

Octave: A = diag([2, 0.5]); x = [1; 1]; A*x

Python: A = np.diag([2.0, 0.5]); x = np.array([1.0, 1.0]); A @ x

Expected: \((2,0.5)\); horizontal stretch by \(2\), vertical shrink by \(1/2\).

E2. Build from \(e_1,e_2\). Reflection through the \(x_2\)-axis sends \((1,0)\mapsto(-1,0)\) and \((0,1)\mapsto(0,1)\).

  1. Write \(A\) on paper.
  2. Apply \(A\) to the three columns of \(X=\begin{bmatrix}1&0&1\\0&1&1\end{bmatrix}\).
  3. Sketch or plot original vs image.

Expected: \(A=\begin{bmatrix}-1&0\\0&1\end{bmatrix}\); \(AX=\begin{bmatrix}-1&0&-1\\0&1&1\end{bmatrix}\).

E3. Shear. Let \(A=\begin{bmatrix}1&1\\0&1\end{bmatrix}\) and unit-square corners as columns \[ X=\begin{bmatrix}0&1&1&0\\0&0&1&1\end{bmatrix}. \] Compute \(Y=AX\). Which corner moved, and how? (Hand-check \(A e_2\).)

Expected: \(Y=\begin{bmatrix}0&1&2&1\\0&0&1&1\end{bmatrix}\); \((0,1)\mapsto(1,1)\) (and \((1,1)\mapsto(2,1)\)) — sheared right.

E4. Rotation. Use \(A=\begin{bmatrix}0&-1\\1&0\end{bmatrix}\) (\(90^\circ\) CCW) on the same unit-square \(X\) from E3. Compute \(Y=AX\) and plot both. Does the square stay a square?

Expected: \(Y=\begin{bmatrix}0&0&-1&-1\\0&1&1&0\end{bmatrix}\); yes — rotated square (still a square).

E5. Adapt the program. Change E4’s matrix to rotation by \(180^\circ\) (or use \(A=-I\)). Apply to \(X\) from E3. Where does \((1,0)\) go?

Expected: \((1,0)\mapsto(-1,0)\); full \(Y=\begin{bmatrix}0&-1&-1&0\\0&0&-1&-1\end{bmatrix}\).

E6 (stretch / 3D idea). Let \[ Q=\begin{bmatrix}0&1&0\\-1&0&0\\0&0&1\end{bmatrix} \] (level flight heading south; Boyd-style body-to-earth axes). Compute \(Q e_1\), \(Q e_2\), \(Q e_3\) and interpret each column as “where that body axis points in earth coordinates.”

Expected: columns \((0,-1,0)\), \((1,0,0)\), \((0,0,1)\) — forward\(\to\)south, left\(\to\)east, up\(\to\)up.

## Demo (optional — run once)

Triangle with vertices $(0,0)$, $(1,0)$, $(0,1)$ as columns of $X$, then rotate $90^\circ$ CCW by $A=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$.

**Octave:**
```matlab
X = [0 1 0; 0 0 1];          % columns are points
A = [0 -1; 1 0];
Y = A*X
plot(X(1,:), X(2,:), 'bo-', Y(1,:), Y(2,:), 'rs-');
axis equal; legend('original','transformed');
```

**Python:**
```python
import numpy as np
import matplotlib.pyplot as plt
X = np.array([[0., 1., 0.], [0., 0., 1.]])  # columns are points
A = np.array([[0., -1.], [1., 0.]])
Y = A @ X
plt.plot(X[0], X[1], 'bo-', Y[0], Y[1], 'rs-')
plt.axis('equal'); plt.legend(['original', 'transformed']); plt.show()
```

**Expected:** $Y=\begin{bmatrix}0&0&-1\\0&1&0\end{bmatrix}$ (columns $(0,0)$, $(0,1)$, $(-1,0)$).

**E1.** Predict, then compute. Let $A=\operatorname{diag}(2,1/2)$ and $x=(1,1)$.

(a) Predict $Ax$ without software.
(b) Check with code.
(c) In one sentence: what did $A$ do geometrically?
