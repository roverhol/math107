Exercises

Query \(x=(2,1)\) and candidates \[ z_1=(2,2),\quad z_2=(0,1),\quad z_3=(3,1),\quad z_4=(2,0),\quad z_5=(1.5,1.5). \]

E1. Compute \(\lVert x-z_i\rVert\) for \(i=1,\ldots,5\). Which candidate is nearest?

Octave:

x = [2; 1];
Z = [2 2; 0 1; 3 1; 2 0; 1.5 1.5];   % row i is z_i
d = sqrt(sum((Z - x').^2, 2))
[~, j] = min(d)   % j is 1-based

Python:

import numpy as np
x = np.array([2.0, 1.0])
Z = np.array([[2, 2], [0, 1], [3, 1], [2, 0], [1.5, 1.5]])
d = np.linalg.norm(Z - x, axis=1)
j = np.argmin(d)   # 0-based index

Expected: distances \(1,\ 2,\ 1,\ 1,\ \sqrt{1/2}\); nearest \(z_5\) (Octave j=5, Python j=4).

E2. Rescale the first feature by \(10\): replace every first coordinate \(a\) by \(10a\) (so \(x\) becomes \((20,1)\), and likewise for each \(z_i\)). Recompute the nearest neighbor(s). Did the answer change?

Expected: distances \(1,\ 20,\ 10,\ 1,\ \sqrt{25.25}\); nearest is a tie between \(z_1\) and \(z_4\) (both distance \(1\)). Yes — the nearest neighbor changed.

## Exercises

Query $x=(2,1)$ and candidates
$$
z_1=(2,2),\quad z_2=(0,1),\quad z_3=(3,1),\quad z_4=(2,0),\quad z_5=(1.5,1.5).
$$

**E1.** Compute $\lVert x-z_i\rVert$ for $i=1,\ldots,5$. Which candidate is nearest?

**Octave:**
```matlab
x = [2; 1];
Z = [2 2; 0 1; 3 1; 2 0; 1.5 1.5];   % row i is z_i
d = sqrt(sum((Z - x').^2, 2))
[~, j] = min(d)   % j is 1-based
```

**Python:**
```python
import numpy as np
x = np.array([2.0, 1.0])
Z = np.array([[2, 2], [0, 1], [3, 1], [2, 0], [1.5, 1.5]])
d = np.linalg.norm(Z - x, axis=1)
j = np.argmin(d)   # 0-based index
```

**Expected:** distances $1,\ 2,\ 1,\ 1,\ \sqrt{1/2}$; nearest $z_5$ (Octave `j=5`, Python `j=4`).

**E2.** Rescale the first feature by $10$: replace every first coordinate $a$ by $10a$ (so $x$ becomes $(20,1)$, and likewise for each $z_i$). Recompute the nearest neighbor(s). Did the answer change?

**Expected:** distances $1,\ 20,\ 10,\ 1,\ \sqrt{25.25}$; nearest is a **tie** between $z_1$ and $z_4$ (both distance $1$). Yes — the nearest neighbor changed.
