What we are doing

Compute eigenpairs with software, verify \(Av\approx\lambda v\), use them to explain the Lab 4 mystery (growth vs decay by start direction), interpret complex eigenvalues as rotation/oscillation, and observe orthogonal eigenvectors for a symmetric / normal-mode style matrix.

Learning objectives

  1. Compute eigenvalues and eigenvectors of a general matrix with software.
  2. Verify \(Av\approx\lambda v\) numerically.
  3. Use dominant eigenbehavior to explain a simulated system.
  4. Interpret complex eigenvalues as rotation/oscillation behavior.
  5. Explore a symmetric-matrix or normal-mode example and observe orthogonal eigenvectors.

Math connections

Eigenvectors as persistent directions (Lecture 35); characteristic equation and complex eigenvalues (Lecture 36); software + dominant behavior + normal-mode demo (Lecture 37). Lab 4 recorded the mystery without eigenvalues; today we close that loop.

Key syntax (this lab)

Task Octave Python
Eigenvalues only eig(A) np.linalg.eigvals(A)
Eigenpairs [V,D] = eig(A) vals, V = np.linalg.eig(A)
\(k\)-th eigenvalue D(k,k) vals[k] (0-based)
\(k\)-th eigenvector V(:,k) V[:,k]
Check \(Av-\lambda v\) A*V(:,1) - D(1,1)*V(:,1) A @ V[:,0] - vals[0]*V[:,0]
Dot product v1'*v2 v1 @ v2 (1D)

Indexing reminder: Boyd \(x_1\) is 1-based. Octave is 1-based; NumPy is 0-based. Eigenvector scaling is arbitrary (software may normalize).

Demo (optional — run once)

\[ A=\begin{bmatrix}2&1\\1&2\end{bmatrix}. \]

Octave:

A = [2 1; 1 2];
[V,D] = eig(A)
A*V(:,1) - D(1,1)*V(:,1)   % near zero

Python:

import numpy as np
A = np.array([[2., 1.], [1., 2.]])
vals, V = np.linalg.eig(A)
print(vals)
print(V)
print(A @ V[:,0] - vals[0]*V[:,0])  # near zero

Expected: eigenvalues \(3\) and \(1\); residual vector near \((0,0)\).

Exercises

Pick Octave or Python for the term.

E1. Lab 4 mystery explained. Let \[ B=\begin{bmatrix}1.2&0\\0&0.5\end{bmatrix}. \]

  1. Use software to find eigenpairs of \(B\).
  2. Verify \(Bv=\lambda v\) for each pair (hand or code).
  3. In one sentence: why does \(x_0=(1,0)\) grow while \(y_0=(0,1)\) decays?

Expected: \(\lambda=1.2\) with \(v\sim(1,0)\); \(\lambda=0.5\) with \(v\sim(0,1)\). Growth vs decay follows from \(|\lambda|>1\) vs \(|\lambda|<1\) along those persistent directions.

E2. Verify a nondiagonal matrix. Let \[ A=\begin{bmatrix}0.9&0.2\\0.1&0.8\end{bmatrix} \] (from Lab 4 E1).

  1. Compute eigenpairs with software.
  2. For each pair, print \(\|Av-\lambda v\|\) (or the residual vector). Accept “near zero.”
  3. Which eigenvalue has larger absolute value? Predict the long-run direction of \(A^t x_0\) for a generic \(x_0\).

Expected: eigenvalues \(1\) and \(0.7\) (exactly, up to rounding); dominant \(\lambda=1\) with eigenvector along \((2,1)\) (or parallel). Stabilization toward that mix matches Lab 4.

E3. Simulate and explain. Same \(A\) as E2, \(x_0=(1000,0)\). Run about \(20\) steps (reuse Lab 4 code). Using E2’s eigenpairs, explain in 2–3 sentences why the state approaches a steady mix rather than blowing up or oscillating.

Expected: both \(|\lambda|\le 1\); the \(\lambda=1\) mode persists and the \(|\lambda|=0.7\) mode decays, so \(x_t\) settles along the \(\lambda=1\) eigenvector.

E4. Complex / oscillation. Let \[ R=\begin{bmatrix}0&-1\\1&0\end{bmatrix}. \]

  1. Software eigenvalues (expect near \(\pm i\)).
  2. Compute \(x_0=(1,0)\), \(x_1=Rx_0\), \(x_2\), \(x_3\), \(x_4\) by hand or code.
  3. In one sentence: how do complex eigenvalues relate to the cycling you see?

Expected: \(\lambda=\pm i\); states cycle every \(4\) steps on the unit circle; complex eigenvalues encode pure rotation / oscillation (no real persistent direction).

E5. Symmetric / normal-mode peek. Let \[ S=\begin{bmatrix}2&1\\1&2\end{bmatrix} \] (symmetric; same as the demo).

  1. Get both eigenvectors \(v_1,v_2\) from software.
  2. Compute \(v_1^{\mathsf{T}}v_2\). Are they orthogonal (up to rounding)?
  3. Normal modes (application/demo): for a symmetric vibration-style matrix, orthogonal eigenvectors are the independent “shapes” that stay aligned under \(S\). No differential-equation derivation required — just observe the orthogonality.

Expected: \(v_1^{\mathsf{T}}v_2\approx 0\); yes, orthogonal.

E6 (stretch). Dominant growth. Let \(C=\begin{bmatrix}1.1&0.2\\0.1&0.8\end{bmatrix}\) and \(x_0=(1,1)\). Find eigenpairs; identify the dominant \(|\lambda|\); simulate to \(t=15\) and comment whether \(\|x_t\|\) grows roughly like \(|\lambda_{\mathrm{dom}}|^t\).

## Key syntax (this lab)

| Task | Octave | Python |
|------|--------|--------|
| Eigenvalues only | `eig(A)` | `np.linalg.eigvals(A)` |
| Eigenpairs | `[V,D] = eig(A)` | `vals, V = np.linalg.eig(A)` |

```python
import numpy as np
```
