Vectors and basics

Task Octave Python (NumPy)
Column vector x = [1; 2; 3] x = np.array([1.0, 2.0, 3.0])
Length \(n\) length(x) len(x) or x.size
First / second entry x(1), x(2) x[0], x[1]
Add / scale x+y, 2*x x+y, 2*x
Dot product \(x^{\mathsf{T}}y\) x'*y x @ y or np.dot(x,y)
Plot in 2D plot(x(1), x(2), 'o') plt.scatter(x[0], x[1]) (after import matplotlib.pyplot as plt)

Norm, distance, angle

Task Octave Python (NumPy)
Norm \(\lVert x\rVert\) norm(x) np.linalg.norm(x)
Distance \(\lVert x-y\rVert\) norm(x-y) np.linalg.norm(x-y)
Cosine similarity (a'*b)/(norm(a)*norm(b)) (a @ b)/(np.linalg.norm(a)*np.linalg.norm(b))
Angle (degrees) acosd(cos_th) np.degrees(np.arccos(np.clip(cos_th,-1,1)))

Many candidates (rows of a matrix)

Store each candidate as a row of Z. Query x is a column in Octave examples below (transpose with x' when subtracting from rows).

Task Octave Python (NumPy)
Stack candidates as rows Z = [1 2; 3 4; 5 6] Z = np.array([[1,2],[3,4],[5,6]])
All distances to x d = sqrt(sum((Z - x').^2, 2)) d = np.linalg.norm(Z - x, axis=1)
Nearest index [~, j] = min(d) → 1-based j = np.argmin(d) → 0-based
Smallest distance min(d) np.min(d)

# Vectors and basics {#basics}

| Task | Octave | Python (NumPy) |
|------|--------|----------------|
| Column vector | `x = [1; 2; 3]` | `x = np.array([1.0, 2.0, 3.0])` |
| Length $n$ | `length(x)` | `len(x)` or `x.size` |
| First / second entry | `x(1)`, `x(2)` | `x[0]`, `x[1]` |
| Add / scale | `x+y`, `2*x` | `x+y`, `2*x` |
| Dot product $x^{\mathsf{T}}y$ | `x'*y` | `x @ y` or `np.dot(x,y)` |
| Plot in 2D | `plot(x(1), x(2), 'o')` | `plt.scatter(x[0], x[1])` (after `import matplotlib.pyplot as plt`) |

# Norm, distance, angle {#norm}

| Task | Octave | Python (NumPy) |
|------|--------|----------------|
| Norm $\lVert x\rVert$ | `norm(x)` | `np.linalg.norm(x)` |
| Distance $\lVert x-y\rVert$ | `norm(x-y)` | `np.linalg.norm(x-y)` |
| Cosine similarity | `(a'*b)/(norm(a)*norm(b))` | `(a @ b)/(np.linalg.norm(a)*np.linalg.norm(b))` |
| Angle (degrees) | `acosd(cos_th)` | `np.degrees(np.arccos(np.clip(cos_th,-1,1)))` |

# Many candidates (rows of a matrix) {#neighbors}

Store each candidate as a **row** of `Z`. Query `x` is a column in Octave examples below (transpose with `x'` when subtracting from rows).

| Task | Octave | Python (NumPy) |
|------|--------|----------------|
| Stack candidates as rows | `Z = [1 2; 3 4; 5 6]` | `Z = np.array([[1,2],[3,4],[5,6]])` |
| All distances to `x` | `d = sqrt(sum((Z - x').^2, 2))` | `d = np.linalg.norm(Z - x, axis=1)` |
| Nearest index | `[~, j] = min(d)` → **1-based** | `j = np.argmin(d)` → **0-based** |
| Smallest distance | `min(d)` | `np.min(d)` |
