Lecture 07 — Norm, distance, RMS, and variation

Fri Sep 11

Last updated: September 11, 2026.

Reading: Boyd 3.1–3.3 (norm, distance, standard deviation). Quiz 3 prep: Boyd 3.1, 3.2, 3.15 and distance computations. Related objectives: Lectures. Schedule. Quiz 3 is Friday, September 18. Angle and cosine similarity are next class (Lecture 08).

Bring paper. Warm-up while attendance is taken, then fill-in notes, board examples (hand and software), and Check yourself.

Learning objectives

By the end of class, students should be able to:

  1. Compute vector norms and distances.
  2. Interpret norm and distance geometrically and contextually.
  3. Relate norm to RMS and, where appropriate, variation around an average.
  4. Use software to calculate distances in dimensions too large for hand computation.

Warm-up

Let \(u=(3,-4)\) and \(v=(0,5)\).

  1. Compute \(u^{\mathsf{T}}u\) and \(\sqrt{u^{\mathsf{T}}u}\) by hand.

  2. Without a calculator, which is larger: \(\lVert u\rVert\) or \(\lVert v\rVert\)? Brief reason.

Fill in

The Euclidean norm of an \(n\)-vector \(x\) is \[ \lVert x\rVert = \sqrt{x_1^2+\cdots+x_n^2} = \sqrt{\underline{\hspace{2.4cm}}}. \] It measures the \(\underline{\hspace{2.0cm}}\) of \(x\). For a scalar, \(\lVert x\rVert\) is the \(\underline{\hspace{2.0cm}}\).

Key properties (same size vectors; \(\beta\) a scalar): - \(\lVert \beta x\rVert = \underline{\hspace{2.4cm}}\,\lVert x\rVert\) - \(\lVert x+y\rVert \leq \lVert x\rVert + \lVert y\rVert\) (triangle inequality) - \(\lVert x\rVert \geq 0\), and \(\lVert x\rVert=0\) only when \(x=\underline{\hspace{1.2cm}}\)

The RMS (root-mean-square) value is \[ \mathrm{rms}(x) = \frac{\lVert x\rVert}{\sqrt{n}} = \sqrt{\frac{x_1^2+\cdots+x_n^2}{n}}. \] It describes a \(\underline{\hspace{2.4cm}}\) size of an entry, and is useful when comparing vectors of different \(\underline{\hspace{2.0cm}}\).

The distance between \(n\)-vectors \(a\) and \(b\) is \[ \mathrm{dist}(a,b) = \lVert a-b\rVert. \] Geometrically this is the length of the \(\underline{\hspace{2.4cm}}\) from \(a\) to \(b\). Two vectors are “close” when this distance is \(\underline{\hspace{1.6cm}}\) (relative to the application).

The average is \(\mathrm{avg}(x)=\frac{1}{n}\mathbf{1}^{\mathsf{T}}x\). The de-meaned vector is \(\tilde{x}=x-\mathrm{avg}(x)\mathbf{1}\). The standard deviation is \[ \mathrm{std}(x)=\mathrm{rms}(\tilde{x})=\frac{\lVert x-\mathrm{avg}(x)\mathbf{1}\rVert}{\sqrt{n}}, \] which measures typical \(\underline{\hspace{2.8cm}}\) of the entries from their average.

Boyd’s identity: \(\mathrm{rms}(x)^2 = \mathrm{avg}(x)^2 + \mathrm{std}(x)^2\).

Software (keep this page open)

In this course we use either Octave or Python for norms and distances.

Octave (column vectors are fine):

x = [3; -4; 0];
norm(x)                 % Euclidean norm
sqrt(x'*x)              % same idea via the inner product
y = [1; 2; -1];
norm(x-y)               % distance ||x-y||

Python (NumPy):

import numpy as np
x = np.array([3.0, -4.0, 0.0])
np.linalg.norm(x)       # Euclidean norm
np.sqrt(x @ x)          # same idea via the inner product
y = np.array([1.0, 2.0, -1.0])
np.linalg.norm(x - y)   # distance ||x-y||

Handy formulas (either language): - \(\mathrm{rms}(x)=\lVert x\rVert/\sqrt{n}\) - \(\mathrm{avg}(x)=\frac{1}{n}\sum_i x_i\) (Octave mean(x), Python np.mean(x)) - \(\mathrm{std}(x)\) in Boyd’s sense is the RMS of the de-meaned vector (population form with divisor \(n\), not \(n-1\))

Worked in class

W1. Norm by hand and by software (Lachniet-style). Let \[ u = (2,\ -4,\ 0). \] (a) Compute \(\lVert u\rVert\) by hand using \(\sqrt{u^{\mathsf{T}}u}\).

  1. Write the Octave command and the Python command that compute the same value. What should both print?

  2. Form the unit vector \(\hat{u}=u/\lVert u\rVert\). What is \(\lVert\hat{u}\rVert\)?

W2. Distance and nearest neighbor (Quiz 3 / Boyd 3.10–3.11 style). Arcata morning temperatures (°F) for three days: \[ a=(52,51,53),\qquad b=(54,50,55),\qquad c=(60,58,59). \] A new day is \(x=(53,52,54)\).

  1. Compute \(\lVert x-a\rVert\), \(\lVert x-b\rVert\), and \(\lVert x-c\rVert\) by hand or with software.

  2. Which day is the nearest neighbor of \(x\)?

  3. In one sentence, what does “nearest” mean here?

W3. Boolean distance (Boyd 3.1). Suppose \(x\) and \(y\) are Boolean \(n\)-vectors (entries only \(0\) or \(1\)).

  1. Show that \(\lVert x-y\rVert^2\) equals the number of positions where \(x\) and \(y\) disagree.

  2. Therefore \(\lVert x-y\rVert=\sqrt{k}\) where \(k\) is that disagreement count. For \(x=(1,0,1,1,0)\) and \(y=(1,1,0,1,0)\), find \(k\) and \(\lVert x-y\rVert\).

W4. RMS, average, and standard deviation (Boyd 3.15 setup). Let \[ x=(2,4,4,6). \] (a) Compute \(\mathrm{avg}(x)\), \(\lVert x\rVert\), \(\mathrm{rms}(x)\), the de-meaned vector \(\tilde{x}\), and \(\mathrm{std}(x)\).

  1. Check Boyd’s identity \(\mathrm{rms}(x)^2=\mathrm{avg}(x)^2+\mathrm{std}(x)^2\).

  2. Interpret \(\mathrm{std}(x)\) in one short sentence for this data.

W5. Feature scale changes nearest neighbor (Quiz 3 C1.2 style). Two features: area (in \(1000\) ft²) and bedrooms. Houses: \[ h_1=(1.6,\ 2),\qquad h_2=(1.5,\ 2),\qquad h_3=(1.6,\ 4). \] (a) Compute \(\lVert h_1-h_2\rVert\) and \(\lVert h_1-h_3\rVert\). Which house is nearer to \(h_1\)?

  1. Now measure area in square feet instead, so the vectors become \[ \tilde{h}_1=(1600,\ 2),\qquad \tilde{h}_2=(1500,\ 2),\qquad \tilde{h}_3=(1600,\ 4). \] Compute \(\lVert\tilde{h}_1-\tilde{h}_2\rVert\) and \(\lVert\tilde{h}_1-\tilde{h}_3\rVert\). Which house is nearer to \(\tilde{h}_1\) now?

  2. What changed, and why does Boyd warn about units on heterogeneous features?

Check yourself

C1. Let \(w=(1,-2,2)\). Compute \(\lVert w\rVert\) by hand. Then write one Octave line and one Python line that compute it.

C2. Quiz 3 C1.1 style. Observation \(x=(1,2)\). Candidates: \[ z_1=(0,2),\quad z_2=(3,2),\quad z_3=(1,5),\quad z_4=(2,1),\quad z_5=(1,2.5). \] Compute the five distances \(\lVert x-z_i\rVert\) (hand or software). Which candidate is nearest?

C3. Boyd 3.2 style. Let \(a\) be an \(n\)-vector and \(b\) an \(m\)-vector, and set \(x=(a,b)\) (stack). Express \(\mathrm{rms}(x)\) in terms of \(\mathrm{rms}(a)\), \(\mathrm{rms}(b)\), \(n\), and \(m\).

C4. For \(t=(10,10,10,14)\), find \(\mathrm{avg}(t)\) and \(\mathrm{std}(t)\). Use Boyd’s definition (RMS of the de-meaned vector).

C5. True or false, with one sentence: if \(\lVert x\rVert=\lVert y\rVert\), then \(x=y\) or \(x=-y\).

NoteAnswers (Check yourself only)

C1. \(\lVert w\rVert=\sqrt{1+4+4}=3\). Octave: norm([1;-2;2]). Python: np.linalg.norm(np.array([1.,-2.,2.])).

C2. Distances: \(1\), \(2\), \(3\), \(\sqrt{2}\approx 1.414\), \(0.5\). Nearest is \(z_5=(1,2.5)\).

C3. \(\mathrm{rms}(x)=\sqrt{\dfrac{n\,\mathrm{rms}(a)^2+m\,\mathrm{rms}(b)^2}{n+m}}\).

C4. \(\mathrm{avg}(t)=11\). De-meaned \((-1,-1,-1,3)\); \(\mathrm{std}(t)=\sqrt{(1+1+1+9)/4}=\sqrt{3}\).

C5. False. Example: \(x=(1,0)\) and \(y=(0,1)\) have the same norm but are neither equal nor negatives.

## Fill in

The **Euclidean norm** of an $n$-vector $x$ is
$$
\lVert x\rVert = \sqrt{x_1^2+\cdots+x_n^2} = \sqrt{\underline{\hspace{2.4cm}}}.
$$
It measures the $\underline{\hspace{2.0cm}}$ of $x$. For a scalar, $\lVert x\rVert$ is the $\underline{\hspace{2.0cm}}$.

Key properties (same size vectors; $\beta$ a scalar):
- $\lVert \beta x\rVert = \underline{\hspace{2.4cm}}\,\lVert x\rVert$
- $\lVert x+y\rVert \leq \lVert x\rVert + \lVert y\rVert$ (triangle inequality)
- $\lVert x\rVert \geq 0$, and $\lVert x\rVert=0$ only when $x=\underline{\hspace{1.2cm}}$

The **RMS** (root-mean-square) value is
$$
\mathrm{rms}(x) = \frac{\lVert x\rVert}{\sqrt{n}} = \sqrt{\frac{x_1^2+\cdots+x_n^2}{n}}.
$$
It describes a $\underline{\hspace{2.4cm}}$ size of an entry, and is useful when comparing vectors of different $\underline{\hspace{2.0cm}}$.

The **distance** between $n$-vectors $a$ and $b$ is
$$
\mathrm{dist}(a,b) = \lVert a-b\rVert.
$$
Geometrically this is the length of the $\underline{\hspace{2.4cm}}$ from $a$ to $b$. Two vectors are “close” when this distance is $\underline{\hspace{1.6cm}}$ (relative to the application).

The **average** is $\mathrm{avg}(x)=\frac{1}{n}\mathbf{1}^{\mathsf{T}}x$. The **de-meaned** vector is $\tilde{x}=x-\mathrm{avg}(x)\mathbf{1}$. The **standard deviation** is
$$
\mathrm{std}(x)=\mathrm{rms}(\tilde{x})=\frac{\lVert x-\mathrm{avg}(x)\mathbf{1}\rVert}{\sqrt{n}},
$$
which measures typical $\underline{\hspace{2.8cm}}$ of the entries from their average.

Boyd’s identity: $\mathrm{rms}(x)^2 = \mathrm{avg}(x)^2 + \mathrm{std}(x)^2$.

## Software (keep this page open)

In this course we use either Octave or Python for norms and distances.

**Octave** (column vectors are fine):
```matlab
x = [3; -4; 0];
norm(x)                 % Euclidean norm
sqrt(x'*x)              % same idea via the inner product
y = [1; 2; -1];
norm(x-y)               % distance ||x-y||
```

**Python** (NumPy):
```python
import numpy as np
x = np.array([3.0, -4.0, 0.0])
np.linalg.norm(x)       # Euclidean norm
np.sqrt(x @ x)          # same idea via the inner product
y = np.array([1.0, 2.0, -1.0])
np.linalg.norm(x - y)   # distance ||x-y||
```

Handy formulas (either language):
- $\mathrm{rms}(x)=\lVert x\rVert/\sqrt{n}$
- $\mathrm{avg}(x)=\frac{1}{n}\sum_i x_i$ (Octave `mean(x)`, Python `np.mean(x)`)
- $\mathrm{std}(x)$ in Boyd’s sense is the RMS of the de-meaned vector (population form with divisor $n$, not $n-1$)
